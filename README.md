# 🎀 باربي Barbii — منصة تجارة أطفال متكاملة

> **PWA + POS + إدارة** — متجر إلكتروني للأطفال يعمل بدون إنترنت، مع نقاط بيع للكاشير ولوحة إدارة كاملة. عربي بالكامل (RTL)، الأسعار بالدينار العراقي، والدفع عند الاستلام.

## ✨ المميزات

| القسم | الوصف |
|---|---|
| 🛍️ **المتجر** | كتالوج منتجات أطفال (ملابس، ألعاب، أحذية، مدرسة، إكسسوارات، أطفال صغار)، بحث فوري، فلترة بالفئة والعمر، ترتيب بالسعر، سلة تسوق، إتمام طلب مع توصيل لجميع المحافظات العراقية |
| 🧾 **نقاط البيع POS** | واجهة كاشير سريعة: بحث بالرمز SKU/الباركود، خصم %، حساب الباقي، طباعة إيصال، تقرير مبيعات اليوم |
| 📊 **الإدارة** | إحصائيات (مبيعات اليوم، الطلبات، مخزون منخفض)، رسم بياني لمبيعات 7 أيام، إدارة المنتجات (إضافة/تعديل/حذف)، إدارة الطلبات وتغيير حالتها، إعدادات المتجر، تصدير البيانات |
| 📲 **PWA** | تثبيت على الجوال، عمل كامل بدون إنترنت (Service Worker)، أيقونات ومانيفست |

## 🚀 التشغيل

لا حاجة لأي تثبيت أو بناء — ملفات ثابتة فقط:

```bash
# الخادم المرفق (موصى به: MIME صحيح للـ PWA + منع الكاش)
python3 serve.py          # المنفذ 8000 افتراضياً
python3 serve.py 8080     # أو منفذ آخر
# ثم افتح: http://localhost:8000
```

> `serve.py` خادم تطوير صغير بلا اعتماديات: يضبط `application/manifest+json` لملف المانيفست،
> ويرسل `Cache-Control: no-store` للصفحات و`sw.js` حتى لا تظهر نسخة قديمة بعد أي تعديل،
> يستمع على `0.0.0.0` ويعمل بـ HTTP/1.1 مع keep-alive ليعمل داخل بيئات المعاينة السحابية،
> ويوفّر مسار فحص صحة على `/healthz` (و`/health` و`/ping`).

أو انشر مباشرة على **GitHub Pages** أو **Vercel** أو **Netlify** (اسحب المجلد).

## 🗂️ بنية المشروع

```

├── manifest.webmanifest  # تعريف PWA
├── sw.js                 # Service Worker (أوفلاين)
├── serve.py              # خادم تطوير محلي (بلا اعتماديات)
├── css/style.css         # التصميم المتجاوب RTL
├── js/data.js            # البيانات الأولية (24 منتج + طلبات تجريبية)
├── js/app.js             # منطق التطبيق الكامل
└── icons/                # أيقونات التطبيق
```

## 💾 البيانات

- تُحفظ محلياً في `localStorage` (مفتاح `barbii_db_v1`) — لا خادم مطلوب.
- من الإدارة: **تصدير JSON** للنسخ الاحتياطي، أو **إعادة تعيين** للعودة للبيانات الافتراضية.
- التوصيل: مجاني فوق 50,000 د.ع، وإلا 5,000 د.ع (قابل للتعديل من الإعدادات).
